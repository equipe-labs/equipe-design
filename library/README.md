# library/ — 디자인 라이브러리 목록 (L6)

라이브러리에 오르는 스타일 목록과 오리지널 스타일의 토큰이다. 이 폴더에는 스타일 이름만 있다. 추출 스타일이 어디서 왔는지는 이 저장소에 두지 않는다.

## 파일

| 경로 | 내용 |
|---|---|
| `styles.json` | 스타일 39개: 오리지널 30개, 추출 9개. 각 항목에 `id`, `slug`, 이름, `origin`, 설명, 카테고리, 태그, `tokens`(토큰 경로)가 있다 |
| `originals/<slug>/tokens.json` | 오리지널 30개의 DTCG 토큰(색 15개 역할 light·dark, 간격, 반경, 선, 서체, 그림자, 모션) |
| `tools/gen.py` | 오리지널 30개를 만든 스크립트(`python3 gen.py <출력폴더>`, `equipe design render`와 Pillow 필요). 다시 돌리면 색은 대비 보정으로 다시 계산된다 |
| `test/styles.test.ts` | 목록 검사. `npx vitest run -c library/vitest.config.ts` |

## 추출 스타일

- 추출 스타일은 `id`가 `ext-01`~`ext-09`인 불투명한 값이다. 값을 뽑기 전에는 `tokens: null`, `category: "pending"`이고 설명·태그는 비어 있다. 값을 뽑은 뒤 실제 값에 맞춰 채운다.
- **발행(L2)은 비공개 출처 파일을 환경 변수 `EQUIPE_DESIGN_SOURCES`에 적힌 경로에서 읽는다.** 그 파일을 `id`로 이 목록과 이어 붙여 `PUT /admin/styles/{slug}`(L0 `StyleUpsert`)로 보낸다. 보낼 때 `id`와 `tokens`는 뺀다. 출처 파일은 공개 저장소에 커밋하지 않는다.
- 테스트는 그 파일이 없어도 돌아간다(형식, URL·출처 필드 없음, 자리표시 출처로 이어 붙인 L0 타입 통과). 파일이 있으면 실제 출처로 L0 타입을 검사하고, `library/**` 전체에 출처 서비스 이름·도메인이 0건인지 확인한다.

## 라이선스 고지

- 오리지널 30개의 서체는 모두 OFL-1.1(Google Fonts)이다. 토큰에는 `fontLicense: OFL-1.1`로 적혀 있다. 서체 파일을 함께 내보낼 때만 OFL 문구를 넣는다.
- 오픈소스(MIT, Apache-2.0)에서 받은 값은 그 라이선스가 요구하는 고지를 **내려받는 파일의 `LICENSE`·`NOTICE`에만** 넣는다. 고지 원문은 비공개 출처 파일 옆에 두고, 발행 때 해당 스타일의 내려받는 파일에 붙인다. 이 목록·API 응답·화면에는 넣지 않는다.
- 로고, 전용 서체, 아이콘, 일러스트는 어느 스타일에도 담지 않는다.

## 66개 레지스트리와의 관계

- `packages/registry`의 66개 컴포넌트(T-528)는 모양과 동작을 맡는다. 색은 비워 둔다(`cssVars`가 비어 있음). 스타일은 색, 서체, 간격, 반경, 모션을 맡는다.
- 사용자는 스타일 하나를 골라 그 스타일의 `shadcn` 출력(CSS 변수)을 넣는다. 그러면 66개 컴포넌트가 모두 그 스타일로 그려진다. 스타일마다 컴포넌트를 따로 두지 않는다. 그래서 L0의 release `components`는 비어 있다.
- 스타일 `slug`와 레지스트리 항목 이름은 겹치지 않는다(테스트로 확인). 나중에 스타일을 레지스트리 theme 항목으로 내보내도 같은 URL 아래에서 부딪히지 않는다.
